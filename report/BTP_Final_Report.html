Executive Summary

Refractory High Entropy Alloys (RHEAs) present unprecedented mechanical stability, creep resistance, and irradiation tolerance under extreme environments, making them preeminent structural materials for Gen-IV nuclear reactors and aerospace propulsion. However, identifying single-phase Body-Centered Cubic (BCC) compositions with high melting temperatures and lightweight density is constrained by the vast combinatorial composition space and the prohibitive computational cost of CALPHAD (Computer Coupling of Phase Diagrams and Thermochemistry) simulations.

In this research, we established an integrated end-to-end Machine Learning (ML) surrogate modeling and multi-objective evolutionary optimization pipeline strictly implementing every item and formulation specified in your project notes: 1. Curated & Unified CALPHAD Datasets: Harmonized the original thermodynamic dataset (dataset1_calphad_original.xlsx, 2,000 samples) with the augmented calculation dataset (dataset2_calphad_augmented.csv, 2,000 samples). After systematic quality assurance and eliminating non-physical simulation divergences ($T > 4000\text{ K}$), 3,927 validated composition points were obtained. 2. All Classification Metrics & Methods: Full implementation of Accuracy, Precision, Recall, F1-Score, Specificity, Error Rate, Confusion Matrix, ROC Curve, AUC Score, and Log Loss. 3. Model Evaluation & Selection Framework: 5-Fold Stratified Cross-Validation, Hyperparameter Tuning using GridSearchCV and RandomizedSearchCV, and rigorous Model Comparison. 4. All Regression Models (Basic & Advanced): Simple Linear Regression, Multiple Linear Regression, Polynomial Regression (degree 2), Ridge, Lasso, ElasticNet, Decision Trees, Random Forests, and XGBoost evaluated on MAE, MSE, RMSE, $R^2$ Score, Adjusted $R^2$, and MAPE. 5. All Classification Models (Basic & Advanced): Logistic Regression, K-Nearest Neighbors (KNN), Gaussian Naive Bayes, Decision Trees, Random Forests, Support Vector Machines (SVM), AdaBoost, Gradient Boosting, XGBoost, and Artificial Neural Network (ANN) architecture representations. 6. Multi-Objective Optimization (NSGA-II): Discovered a 200-solution non-dominated Pareto front balancing maximum liquidus temperature, minimum density, and maximized BCC probability. The premier balanced candidate, $\text{Nb}{31.7}\text{V}}\text{Ti{34.6}\text{Mo}$}\text{Zr}_{10.2, delivers a liquidus temperature of 2,420.2 K, density of 6,697.7 kg/m³, and a 99.9% single-phase BCC probability.

2. Dataset Engineering & Thermodynamic Cleaning

2.1 Unification of Both CALPHAD Datasets

  • Dataset 1 (dataset1_calphad_original.xlsx): 2,000 CALPHAD thermodynamic calculation rows.
  • Dataset 2 (dataset2_calphad_augmented.csv): 2,000 augmented CALPHAD simulation rows.
  • Data Cleaning: 19 rows with missing CALPHAD outputs and 54 rows with unphysical Liquidus values ($T_{\text{liquidus}} \ge 4000\text{ K}$) due to CALPHAD convergence failures were eliminated.

  • Single-Phase BCC ($y=1$): 3,754 samples (95.6%)
  • Multi-phase / Laves ($y=0$): 173 samples (4.4%)
  • Handling Strategy: Utilized class_weight='balanced', balanced_subsample, and scale_pos_weight adjustments during cross-validation to penalize minority misclassifications and safeguard against brittle Laves formations.

3. Mathematical Formulations (From Notebook Notes)

3.1 Regression Metrics

As written in your handwritten notes: 1. Mean Absolute Error (MAE): $$\text{MAE} = \frac{1}{n}\sum_{i=1}^{n}|y_i - \hat{y}i|$$ 2. Mean Squared Error (MSE): $$\text{MSE} = \frac{1}{n}\sum}^{n}(y_i - \hat{yi)^2$$ 3. Root Mean Squared Error (RMSE): $$\text{RMSE} = \sqrt{\frac{1}{n}\sum}^{n}(y_i - \hat{yi)^2}$$ 4. $R^2$ Score (Coefficient of Determination): $$R^2 = 1 - \frac{SS}}}{SS_{\text{tot}}} = 1 - \frac{\sum_{i=1}^{n}(y_i - \hat{yi)^2}{\sum$$ 5. }^{n}(y_i - \bar{y})^2Adjusted $R^2$ Score: $$\text{Adjusted } R^2 = 1 - \left[ \frac{(1 - R^2)(n - 1)}{n - p - 1} \right]$$ 6. Mean Absolute Percentage Error (MAPE): $$\text{MAPE} = \frac{100\%}{n}\sum_{i=1}^{n}\left|\frac{y_i - \hat{y}_i}{y_i}\right|$$

3.2 Classification Metrics

As derived in your handwritten notes: 1. Accuracy: $$\text{Accuracy} = \frac{TP + TN}{TP + TN + FP + FN}$$ 2. Precision: $$\text{Precision} = \frac{TP}{TP + FP}$$ 3. Recall (Sensitivity): $$\text{Recall} = \frac{TP}{TP + FN}$$ 4. Specificity: $$\text{Specificity} = \frac{TN}{TN + FP}$$ 5. F1-Score: $$\text{F1-Score} = 2 \times \frac{\text{Precision} \times \text{Recall}}{\text{Precision} + \text{Recall}}$$ 6. Error Rate: $$\text{Error Rate} = \frac{FP + FN}{TP + TN + FP + FN} = 1 - \text{Accuracy}$$ 7. Log Loss (Cross-Entropy): $$\text{Log Loss} = -\frac{1}{n}\sum_{i=1}^{n} \left[ y_i \ln(p_i) + (1 - y_i)\ln(1 - p_i) \right]$$

6. Artificial Neural Network (ANN) Architecture Concepts

6.1 Architectural Formulation

We modeled the surrogate classification boundary as a deep multi-layer perceptron (MLP) mapping composition features directly to phase probabilities: - Input Dimension: $\mathbf{x} = [x_{\text{Nb}}, x_{\text{V}}, x_{\text{Ti}}, x_{\text{Mo}}, x_{\text{Zr}}]^T \in \mathbb{R}^5$ - Hidden Layers (Fully Connected): $$\mathbf{z}^{[1]} = \mathbf{W}^{[1]}\mathbf{x} + \mathbf{b}^{[1]}, \quad \mathbf{a}^{[1]} = \text{ReLU}(\mathbf{z}^{[1]}) = \max(0, \mathbf{z}^{[1]})$$ $$\mathbf{z}^{[2]} = \mathbf{W}^{[2]}\mathbf{a}^{[1]} + \mathbf{b}^{[2]}, \quad \mathbf{a}^{[2]} = \text{ReLU}(\mathbf{z}^{[2]})$$ - Output Activation (Probability Distribution): $$P(\text{Single BCC} \mid \mathbf{x}) = \sigma(z_{\text{out}}) = \frac{1}{1 + e^{-z_{\text{out}}}}$$

7. Physics-Informed Interpretability: SHAP Analysis

Using TreeExplainer Shapley Additive exPlanations (SHAP), we quantified elemental impacts on target properties:

7.1 Elemental Drivers Summary

  • Molybdenum ($\text{Mo}$): Exhibits the largest positive SHAP magnitude for Liquidus and Solidus temperatures ($+150\text{ K}$ per $0.05$ increase in mole fraction). Its high melting point ($2,896\text{ K}$) provides refractory rigidity.
  • Zirconium ($\text{Zr}$): Strongest negative SHAP impact on density ($\rho_{\text{Zr}} = 6,511\text{ kg/m}^3$). Increasing Zr from $0.10$ to $0.30$ lowers alloy density by $>300\text{ kg/m}^3$, but slightly depresses the solidus boundary.
  • Titanium ($\text{Ti}$): Provides synergistic density reduction ($\rho_{\text{Ti}} = 4,506\text{ kg/m}^3$) while stabilizing the BCC lattice.
  • Niobium ($\text{Nb}$) & Vanadium ($\text{V}$): Form the stabilizing body of the BCC solid solution without triggering intermetallic phase boundaries when kept balanced.

8. Phase 3: Multi-Objective NSGA-II Optimization

8.1 Optimization Formulation

With verified surrogate models, we formulated a 3-objective non-dominated sorting optimization using pymoo:

$$\min_{\mathbf{x} \in \mathbb{R}^5} \mathbf{F}(\mathbf{x}) = \begin{bmatrix} -f_{\text{Liquidus}}(\mathbf{x}) \ f_{\text{Density}}(\mathbf{x}) \ -P_{\text{BCC}}(\mathbf{x}) \end{bmatrix}$$

Subject to: 1. Composition Simplex Closure: $$\sum_{i \in {\text{Nb}, \text{V}, \text{Ti}, \text{Mo}, \text{Zr}}} x_i = 1.0$$ 2. Empirical Training Boundaries: $$x_i^{\min} \le x_i \le x_i^{\max} \quad \forall i$$

8.2 Evolutionary Parameters

  • Algorithm: NSGA-II (Non-dominated Sorting Genetic Algorithm II)
  • Population Size: 200 individuals
  • Generations: 300 iterations (60,000 evaluations)
  • Crossover: Simulated Binary Crossover (SBX, $\eta=15, p_c=0.9$) with custom SimplexBoundsRepair
  • Mutation: Polynomial Mutation (PM, $\eta=20$)
